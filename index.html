About Me

LIMO Robot

The LIMO Robot project focuses on autonomous navigation using ROS (Robot Operating System). The robot is programmed to explore and map a maze-like environment, utilizing real-time sensor data for localization and obstacle avoidance.

  • Mapped the environment using Odometry and LiDAR data with RTAB-Map.
  • Configured RTAB-Map's global and local planners for effective navigation.
  • Optimized obstacle avoidance and path planning by tuning system parameters.
  • Improved overall stability and performance for smoother navigation.

Arena Design

This project involves designing and constructing a maze-like arena inspired by Changi Airport Terminal 2, tailored for LIMO Robot navigation and testing.

  • Researched architectural and visual elements of Terminal 2 for thematic accuracy.
  • Used SolidWorks to design the arena before physical construction, optimizing material usage.
  • Ensured obstacle dimensions were aligned with the robot’s sensing capabilities for accurate detection.
