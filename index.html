Limo Robot

Programming a limo robot to navigate a maze like structure using ROS.

  • Explored and Mapped the arena layout using Odometry and LiDar data.
  • Learned and used RTAB-Map for mapping.
  • Using the RTAB-Map global and local planner to create a route to navigate the maze.
  • Fine tuned the parameters of the limo robot for better navigation and obstacle avoidance.
